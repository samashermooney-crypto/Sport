# Servicio de importación con asistencia

Si prefiere no ejecutar las importaciones usted mismo — o si su sistema anterior produce exportaciones complicadas — el equipo de Athlentry hará la migración con usted.

## Cómo funciona

1. Abra **Ayuda → Contactar soporte** (o la opción de asistencia en la página de Importaciones) y elija **Importación con asistencia**.
2. Indíquenos de qué sistema viene y aproximadamente cuántas personas y temporadas tiene.
3. Le responderemos con un enlace seguro para subir sus archivos. Nunca envíe por correo archivos con datos de menores.
4. Ejecutamos las importaciones en su organización en una llamada con pantalla compartida, revisamos duplicados con usted y confirmamos los resultados juntos.

## Qué preparar

- Todas las exportaciones CSV/Excel que pueda obtener de su sistema actual.
- Una lista de sus programas y temporadas.
- 45–60 minutos para la llamada.

La importación con asistencia no tiene costo durante la incorporación.
