# Switch to Athlentry from SportsEngine

## Export your data

From SportsEngine HQ:

- Use **Registration → Reports** to export registrant data as CSV → Athlentry _People_ and _Registrations_ imports.
- Export **rosters** per team → _Teams_ then _Rosters_.
- Export your **schedule** if available, or rebuild it in Athlentry after importing facilities.
- Download invoices/payment history if your directory allows → _Payment history_ import (recorded as external, never re-charged).

## Import order

Facilities → People → Teams → Rosters → Schedule → Registrations → Payment history → Volunteer hours. Each later import matches records the earlier ones created.

## What does not transfer

- SportsEngine website content — rebuild pages on your Athlentry site (it is faster than it sounds, and you can publish in minutes).
- Background-check statuses — import them as _Credentials_ with expiry dates if you have the records, or require fresh checks under Compliance.
- Signed documents — collect fresh signatures at next registration.
