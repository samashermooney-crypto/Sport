# Cambie a Athlentry desde SportsEngine

## Exporte sus datos

Desde SportsEngine HQ:

- Use **Registration → Reports** para exportar datos de registrados en CSV → importaciones de _Personas_ y _Registros_.
- Exporte las **plantillas** por equipo → _Equipos_ y luego _Plantillas_.
- Exporte su **calendario** si está disponible, o reconstrúyalo en Athlentry.
- Descargue el historial de pagos → importación de _Historial de pagos_ (se registran como externos, nunca se vuelven a cobrar).

## Orden de importación

Instalaciones → Personas → Equipos → Plantillas → Calendario → Registros → Historial de pagos → Horas de voluntariado.

## Lo que no se transfiere

- Contenido del sitio web de SportsEngine — recree las páginas en su sitio de Athlentry.
- Estados de verificación de antecedentes — impórtelos como _Credenciales_ con fechas de vencimiento si tiene los registros.
- Documentos firmados — recoja firmas nuevas en el próximo registro.
