# Contactar al soporte

Abra Ayuda y elija Contactar soporte. Indique la pantalla que usaba, qué esperaba que ocurriera y los pasos que llevaron al problema. La solicitud incluye una ruta de página depurada y el contexto de la organización para que el equipo pueda asignarla.

No incluya contraseñas, datos de tarjetas, información médica, nombres de menores ni archivos de exportación. Use Asistencia de importación para planificar una migración; el equipo ofrecerá un método seguro aprobado si necesita un archivo.
