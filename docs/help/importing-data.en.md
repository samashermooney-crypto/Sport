# Importing data safely

Download the generic template for the record type you are moving. Export only the data you need, keep the source copy access-controlled, and remove columns that are not part of the import.

Upload a CSV or XLSX file, map its actual headers to Athlentry fields, then review the preview. Correct errors in a copy of the source file and upload it again. Possible duplicate people require an explicit create or skip choice.

Import prerequisites first: people and facilities before rosters and schedules. Historical payment rows are external history; they never charge a payment method. Imported credentials are pending staff review, even if the source file says verified. A document can be attached only when it is included in the credential ZIP.

After committing, compare row counts and totals with your source. A batch can be rolled back; records changed after import are left for staff review, while financial and compliance evidence is retained.
