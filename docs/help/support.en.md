# Contacting support

Open Help and choose Contact support. Include the screen you were using, what you expected to happen, and the steps that led to the issue. The request includes a sanitized page path and organization context so support can route it.

Do not include passwords, payment card details, medical information, child names, or source export files. Use Concierge import for migration planning; support will provide an approved secure transfer method if a file is needed.
