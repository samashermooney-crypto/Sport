# Concierge import support

If you would like help planning an import, contact Athlentry platform support through Contact support in the help center and choose **Concierge import**.

Describe the record types you need to move, the source file formats, and your target season. Do not attach export files or send children's personal information by email. Support will reply with next steps and, if a file transfer is needed, an approved secure method.

Before the conversation, you can review the generic import templates and prepare an unchanged, access-controlled copy of each export. Availability and export formats vary by source system. Never share source-system passwords.

The support team will confirm the available assistance, scope, timing, and any applicable terms with you before work begins.
